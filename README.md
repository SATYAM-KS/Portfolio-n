## Project Structure
- `index.html` — Main static landing page and pre-rendered SSR DOM.
- `404.html` — Custom 404 error page.
- `favicon.ico` — Site favicon icon.
- `assets/`
  - `animate/` — JavaScript modules, React runtime, and interactive animation logic.
  - `images/` — Image assets, portraits, and SVGs.
  - `fonts/` — Typography webfonts (Geist, Geist Mono, Inspiration, Inter).
  - `videos/` — Hero and interactive background video loops.
  - `css/` — Stylesheets and design tokens.
  - `meta/` — Search metadata and OpenGraph social previews.
